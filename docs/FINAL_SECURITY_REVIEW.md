## 2. Explicit Scope Boundaries & Remaining Limitations

1. **Untrusted Multi-Tenant Builds Are NOT Supported on Host Docker:**
   - Standard Docker / BuildKit container isolation shares the host Linux kernel and is suitable only for **trusted repositories in local or controlled internal environments**. Untrusted public multi-tenant builds require microVM or kernel-level sandboxing (gVisor, Kata Containers, or Firecracker).
2. **Operator-Side vs. In-Pipeline Security Scanning:**
   - Phase 4's Trivy + CycloneDX SBOM + Cosign workflow (`infrastructure/supplychain/assess-image.sh`) is an **operator-side signing workflow** coupled with **backend-enforced production execution gating** (`ArtifactEvidenceService.requireProductionApproval`). Automatic in-pipeline `SECURITY_SCAN` stage worker execution is **not** implemented; `SECURITY_SCAN` stages remain declarative unless executed externally and submitted as signed evidence.
3. **Single-Actor Production Approval:**
   - Production deployments and rollbacks enforce `OWNER`-only role + explicit justification + feature flag + signed artifact evidence, but do not yet enforce dual-control / two-person approval.
4. **Environment Keyring vs. Hardware KMS:**
   - `EnvKeyringSecretKeyProvider` keeps KEKs out of PostgreSQL and supports DEK-only batch rotation, but production multi-tenant deployments should migrate to an external HSM/KMS (AWS KMS, GCP KMS, or HashiCorp Vault Transit).
5. **Organization GitHub App Callbacks Fail Closed:**
   - New unverified GitHub Organization installations are intentionally rejected (`403`) until user-to-server `/user/installations` verification is implemented.
6. **NetworkPolicy CNI Dependency:**
   - CloudForge ships default-deny `NetworkPolicy` manifests, but live enforcement depends on the cluster CNI (`kube-router` in K3s, Calico, or Cilium; default `kindnet` does not enforce `NetworkPolicy`).
7. **Server-Side Session Store:**
   - Sessions are stored in-memory in the single Spring Boot process (`CLOUDFORGE_SESSION`). Horizontal scaling of the control plane requires externalized sessions (Redis or Spring Session JDBC).
8. **Static-Check Hygiene:**
   - Checked repository with `git status` and automated scans: zero `.env`, `.pem`, `.key`, kubeconfigs, Grafana passwords, or production secrets are committed in Git.
